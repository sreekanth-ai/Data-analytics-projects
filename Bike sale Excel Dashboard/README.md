# 🚲 Bike Sales Analysis Dashboard (Excel Project)

![Excel](https://github.com/SaiSurajMatta/Bike-Sales-Excel-Dashboard-Project/assets/92928975/b12416c0-5eb3-457b-b90b-26e72240f052)

## 📌 Overview

This project presents an interactive **Excel Dashboard** built using the Bike Buyers dataset.
The objective is to analyze customer demographics and purchasing behavior to understand key factors influencing bike purchases.

The dashboard is designed to provide **clear business insights using Excel tools like Pivot Tables, Charts, and Data Cleaning techniques**.

---

## 🎯 Objective

* Analyze customer buying behavior for bikes
* Identify key demographic patterns influencing purchase decisions
* Explore relationships between income, age, commute distance, and bike purchases
* Build an interactive dashboard for easy data exploration

---

## 📂 Dataset Information

* Source: Kaggle Bike Buyers Dataset
  [Bike Buyers Dataset (Kaggle)](https://www.kaggle.com/datasets/heeraldedhia/bike-buyers?utm_source=chatgpt.com)
* Records: ~1000 customer entries
* Key features:

  * Gender
  * Marital Status
  * Income
  * Age
  * Commute Distance
  * Bike Purchase Status

---

## 🧹 Data Preparation Steps

* Removed duplicate records
* Standardized categorical values (Gender, Marital Status, etc.)
* Created age brackets for segmentation
* Cleaned missing and inconsistent values
* Prepared a working dataset for analysis

---

## 📊 Analysis Approach

* Used **Pivot Tables** for summarizing data
* Built **interactive charts** for visualization
* Created KPI-based insights for decision-making
* Designed dashboard layout for clarity and usability

---

## 📈 Dashboard Insights

### 🔹 1. Income vs Bike Purchase

* Compared average income of customers who purchased vs did not purchase a bike
* Helps identify purchasing power influence

### 🔹 2. Commute Distance Analysis

* Analyzed how travel distance affects bike purchase decisions
* Found patterns in commuting behavior

### 🔹 3. Age Group Segmentation

* Classified customers into:

  * Adolescent
  * Middle-aged
  * Old
* Identified which age group is most likely to purchase bikes
